# מחשבון השקעות – נדל"ן מול בורסה 📊

אפליקציה לטלפון לחישוב השקעות נדל"ן והשקעות בבורסה, ולהשוואה ביניהן. החישובים מבוססים על נתונים היסטוריים מהרבה שנים.
האפליקציה עובדת כולה על המכשיר, גם בלי אינטרנט.

## מסכים
| מסך | מה יש בו |
|---|---|
| **נדל"ן** | מחיר, הון עצמי, מס רכישה אוטומטי לפי מדרגות, עו"ד, תיווך, שיפוץ. משכנתא (שפיצר או קרן שווה, חלק צמוד למדד). שכירות, חודשים ריקים, תחזוקה, ניהול, ביטוח. מס על שכירות (פטור, 10%, שולי), מס שבח ועמלות מכירה. בתוצאות: תשואה ברוטו ונטו, תזרים חודשי, IRR, שווי נטו אחרי מכירה, ערך במונחי היום, ואזהרה כשהמימון חורג מהמותר. |
| **בורסה** | השקעה ראשונית והפקדה חודשית, עליית מחיר ודיבידנד, השקעה מחדש של דיבידנדים, דמי ניהול של הקרן ומהצבירה, עמלת קנייה. סוג חשבון: רגיל, קרן השתלמות או דחיית מס. מס דיבידנד ומס רווחי הון 25%. סימולציית מונטה-קרלו על שנים אמיתיות, וגם כל התקופות הרציפות בהיסטוריה (הגרועה, החציונית והטובה ביותר). |
| **השוואה** | אותו סכום בשתי ההשקעות ולאותה תקופה. מחיר הדירה יכול להיקבע אוטומטית לפי המימון המקסימלי. "השוואה הוגנת": כסף שמוסיפים מהכיס לנדל"ן מושקע גם בבורסה. נקודת איזון (איזו עליית מחירים צריך כדי שהנדל"ן ישתווה). סיכוי לניצחון בסימולציה. בדיקה מול נתוני העבר: "לו הייתם משקיעים בשנה X". שיתוף התוצאה. |
| **כלים** | מחשבון משכנתא, מס רכישה, כמה דירה אפשר לקנות, עלות דמי ניהול לאורך שנים, עצמאות כלכלית (כלל ה-4%), חיסכון ליעד, תרחישים שמורים. |
| **נתונים** | S&P 500 מ-1928, S&P 500 בשקלים, ת"א-125, מדד מחירי הדירות, אינפלציה ושער הדולר. לכל סדרה: גרף, סטטיסטיקות, תקופות החזקה רציפות ומקורות. |

## התקנה בטלפון
**אנדרואיד (APK):** בדף ה-Releases של הריפו, בגרסה `calculator-latest`, מורידים את `InvestmentCalculator.apk` ומתקינים. GitHub Actions בונה אותו מחדש בכל push.

**כל טלפון (אפליקציית ווב):** מעלים את התיקייה `web/` לשרת סטטי, למשל GitHub Pages. בדפדפן בוחרים "הוספה למסך הבית". האפליקציה תעבוד גם בלי חיבור לאינטרנט.

## מבנה הקוד
```
investment-calculator/
  web/            האפליקציה (HTML/CSS/JS, בלי תלויות)
    js/data.js    נתונים היסטוריים, מדרגות מס וקבועים
    js/calc.js    מנוע החישוב (פונקציות טהורות, אפשר להריץ ב-Node)
    js/charts.js  גרפי SVG
    js/app.js     ממשק המשתמש
  tests/          בדיקות יחידה:  node --test investment-calculator/tests/*.test.js
calculator/       מעטפת אנדרואיד (WebView) שטוענת את web/ מתוך ה-assets
```

## הנחות והגבלות
- הנתונים ההיסטוריים של מחירי הדירות ושל ת"א-125 (לפני 2017) הם ערכים שנתיים משוערים. כדאי לעדכן אותם בקובץ `data.js` מול הלמ"ס והבורסה.
- מדרגות מס הרכישה ותקרת הפטור על שכירות מעודכנות ל-2025–2026.
- ריבית המשכנתא קבועה לאורך כל התקופה. בדירה צמודה, ההצמדה מחושבת לפי האינפלציה שהוזנה.
- המחשבון לא כולל את מס היסף על הכנסות הון גבוהות, הטבות מס אישיות ומיסוי של קרן השתלמות מעל התקרה.
- **המחשבון אינו ייעוץ השקעות.**
