# שומר עיניים 🛡️ – סינון תכנים לא צנועים לאנדרואיד

אפליקציה לסינון אתרים ותכנים לא צנועים בטלפון. הסינון חל על **כל** האפליקציות והדפדפנים בטלפון.

## מה היא עושה
- **חוסמת אתרים לא צנועים**: רשימה מובנית של מאות אתרים, וגם זיהוי לפי מילות מפתח בכתובת (porn, xxx, nude ועוד).
- **שכבת הגנה נוספת**: כל שאר הבקשות עוברות דרך שרת ה-DNS המשפחתי של Cloudflare (1.1.1.3), שחוסם גם הוא תוכן למבוגרים ואתרים זדוניים.
- **חיפוש בטוח מחייב**: Google ו-Bing מוגבלים ל-SafeSearch, ‏YouTube למצב מוגבל (Restricted Mode), ו-DuckDuckGo לחיפוש בטוח.
- **חוסמת עקיפות**: חוסמת DNS מוצפן של דפדפנים (DoH) כדי שלא יעקפו את הסינון.
- **קוד נעילה**: כדי לכבות את הסינון או לשנות רשימות צריך להזין קוד.
- **רשימות אישיות**: אפשר להוסיף אתרים לחסימה, או לאשר אתר שנחסם בטעות.
- **הגנה מפני הסרה**: האפליקציה נרשמת כ"מנהל מכשיר", ולכן אי אפשר להסיר אותה בלי לבטל קודם את ההרשאה.
- **עולה אוטומטית** כשהטלפון נדלק.

## איך זה עובד (טכני)
האפליקציה פותחת VPN **מקומי** שלא יוצא מהמכשיר ולוכד רק את בקשות ה-DNS. היא לא מעבירה את שאר התעבורה, ולכן לא מאטה את הגלישה ולא אוספת מידע.

## התקנה
1. בטלפון, פתחו את דף ה-Releases של הריפו והורידו את **ShomerEinayim.apk** מהגרסה `latest-build`.
2. אשרו "התקנה ממקורות לא ידועים" והתקינו.
3. פתחו את האפליקציה, לחצו **הפעל סינון** ואשרו את בקשת ה-VPN.

## הגדרה מומלצת להגנה מלאה
1. **קוד נעילה**: הגדירו קוד ותנו אותו לאדם אחר (בן/בת זוג, הורה, רב, חבר).
2. **VPN תמידי**: בהגדרות ← רשת ← VPN ← ⚙️ ליד "שומר עיניים", הפעילו את **VPN תמידי** ואת **חסום חיבורים ללא VPN**. כך אין גלישה בכלל כשהסינון כבוי.
3. **DNS פרטי**: בהגדרות ← רשת ← DNS פרטי בחרו **כבוי**. אחרת אנדרואיד עלול לעקוף את הסינון.
4. **הגנה מפני הסרה**: לחצו על הכפתור באפליקציה ואשרו.

## מגבלות (חשוב לדעת)
- הסינון עובד לפי כתובות אתרים (DNS) ולא לפי תוכן התמונות. אתרים כלליים (רשתות חברתיות) לא ייחסמו אוטומטית. אפשר להוסיף אותם ידנית ברשימה האישית.
- מי שיודע את קוד הנעילה, או בלי "VPN תמידי" מוגדר, יכול לנתק את ה-VPN מהגדרות המערכת.
- זה לא תחליף לסינון מוסמך (כמו נטפרי / רימון) למי שזקוק להגנה ברמה גבוהה.
